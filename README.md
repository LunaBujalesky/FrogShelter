# FrogShelter
API for frog adoptions.
Frog Shelter es una API similar a la de pokemon donde los usuarios pueden adoptar y evolucionar ranas virtuales. El frontend consume una API REST implementada en Express mediante el router adoption.router.js.
Siguientes implementaciones: "mis ranas" para ver ranas adoptadas, poder tomar tu rana y exportarla para tenerlo como plugin del navegador u en otro sitio web. Frontend de la api.

## Características

- Listar ranas disponibles.
- Consultar rana por ID.
- Adoptar ranas.
- Evolucionar ranas adoptadas.
- Frontend básico para interactuar con la API.
- Tests funcionales con Jest y Supertest.
- Dockerización completa.
