# FrogShelter
Web app for frog adoptions.
Frog Shelter es una aplicación web donde los usuarios pueden adoptar y evolucionar ranas virtuales. El frontend consume una API REST implementada en Express mediante el router adoption.router.js.

## Características

- Listar ranas disponibles.
- Consultar rana por ID.
- Adoptar ranas.
- Evolucionar ranas adoptadas.
- Frontend básico para interactuar con la API.
- Tests funcionales con Jest y Supertest.
- Dockerización completa.
